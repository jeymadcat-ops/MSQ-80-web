# MSQ-80 on the web

The built page (generated by `web/build.ps1`, do not edit): `index.html` with `style.css`, `link.js`, `panel.js`, `device.js`, `app.js` and `msq8.wasm`, and `msq8-single.html`, the whole page in one file.
Serve this folder from any static host (it needs `https://` or `localhost` for the audio and WebAssembly). The engine is the C code in `engine/`, compiled to WebAssembly.
